# 🎯 Habit Tracker Service

Современное веб-приложение для отслеживания привычек и достижения целей. Разработано на стеке React + TypeScript с хранением данных в браузере (LocalStorage).

## ⚡ Функционал

- **Авторизация:** Регистрация, вход в систему и восстановление пароля.
- **Управление привычками:** Создание привычек, привязка к дням недели, трекер стриков (серий).
- **Цели:** Постановка целей с дедлайнами и визуализацией прогресса.
- **Статистика:**
  - Детальная статистика по месяцам.
  - Прогресс за текущую неделю.
  - Мотивационные сообщения и диаграммы эффективности.
- **Интерфейс:** Адаптивный дизайн, темная/светлая палитра, уведомления об ошибках и успехе.

## 🛠 Технологический стек

- **Core:** React 18, TypeScript, Vite
- **Стилизация:** Tailwind CSS
- **Навигация:** React Router DOM
- **Иконки:** Lucide React
- **Хранение данных:** LocalStorage

## 🚀 Как запустить проект

### 1. Установка зависимостей

Откройте терминал в папке с проектом и выполните:

```bash
npm install
```
