# 🌿 Habit Tracker Service

Персональный веб-сервис для отслеживания привычек и целей. Помогает формировать полезные привычки, ставить долгосрочные цели и визуализировать свой прогресс.

## ✨ Возможности

- **📝 Управление привычками** — создание, редактирование и отслеживание ежедневных привычек.
- **🎯 Цели с дедлайнами** — постановка целей и мониторинг прогресса в процентах.
- **🔥 Система стриков** — подсчет серии успешных дней подряд.
- **📊 Статистика** — наглядные графики выполнения по дням недели.
- **📱 Адаптивный дизайн** — удобная работа на ПК (сайдбар) и мобильных устройствах (нижнее меню).
- **💾 Локальное хранение** — данные сохраняются в браузере и не теряются при перезагрузке.

## 🛠 Технологический стек

- **React 18** + **TypeScript**
- **Vite** — быстрая сборка проекта
- **Tailwind CSS** — стилизация и адаптивность
- **Zustand** — управление состоянием
- **React Router v6** — маршрутизация
- **Lucide React** — библиотека иконок
