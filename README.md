# 🎯 Habit Tracker Service

Веб-приложение для отслеживания привычек и целей. Разработано с использованием современного стека (React + TypeScript) с полноценной имитацией бэкенда и базы данных.

## ⚡ Функционал

- **Авторизация:** Регистрация и вход в систему (с валидацией данных).
- **Управление привычками:** Создание, редактирование и удаление привычек с привязкой к дням недели.
- **Трекинг:** Отметка выполнения привычек с подсчетом стрика (серии).
- **Цели:** Создание целей с дедлайнами и визуальный индикатор прогресса.
- **Статистика:** Аналитика выполненных задач и текущих показателей.
- **Архитектура:** Разделение на клиентскую часть и API (JSON Server).

## 🛠 Технологический стек

**Frontend:**

- **React 18** + **TypeScript** (строгая типизация)
- **Vite** (быстрая сборка)
- **Tailwind CSS** (стилизация)
- **React Router DOM** (навигация)
- **Lucide React** (иконки)

**Backend:**

- **JSON Server**
